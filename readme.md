# ⚡ TaskFlow Hyper Studio — Next-Gen Productivity Experience

An award-winning, state-of-the-art productivity studio crafted with a futuristic **Bento Grid architecture**, **interactive Stardust particle physics**, **3D card perspective tilt & specular glare**, **Dynamic Island Focus HUD**, **Fullscreen Zen Focus Portal**, **AI Productivity Coach**, **30-Day Activity Heatmap**, and a **Trophy Showcase System**.

Crafted 100% with pure Vanilla HTML5, CSS3 Custom Properties, and ES6+ JavaScript — zero bundler, npm, or backend dependencies required!

---

## 🌟 Cutting-Edge Features & Innovations

### 1. 🌌 Floating Stardust Particle Physics Canvas
* Real-time interactive node canvas (`#stardust-canvas`) that floats behind the Bento Matrix.
* Dynamic proximity connections: nearby nodes form faint glowing constellations.
* Interactive cursor repulsion and constellation beams when moving the mouse.

### 2. 🎴 3D Perspective Card Tilt & Specular Light Glare
* Physics-based 3D rotation (`rotateX`, `rotateY`) on mouse move across every studio Bento card.
* Specular radial glare spotlights that follow the pointer across card surfaces with realistic depth.

### 3. 🧘 Distraction-Free Fullscreen Zen Mode Portal
* Enter Zen Mode with one click or press <kbd>Z</kbd>.
* Features an animated breathing pulse ring, giant glowing countdown digits, active target task, and randomized mindfulness wisdom quotes.
* Seamlessly synchronized in real-time with the Cyber Focus Studio Pomodoro timer.

### 4. 🏝️ Dynamic Island Focus HUD
* Apple Dynamic Island-style floating pill in the top navigation bar.
* Pops up with an animated pulsing dot and live countdown whenever a focus sprint is active.
* Click directly on the Dynamic Island to jump straight into Fullscreen Zen Mode.

### 5. 🤖 AI Productivity Coach & Sprint Launcher
* Context-aware productivity intelligence banner analyzing your pipeline in real time.
* Dynamically detects high-priority active tasks and suggests custom focus sprints.
* **One-Click Sprint**: Press `Start 25m Sprint` to instantly lock onto your top priority task, configure the timer, and begin flow state.

### 6. 📊 30-Day Activity Velocity Heatmap
* GitHub-style 30-day velocity matrix visualizing daily completion density from `lv0` (empty) to `lv3` (intense velocity).
* Interactive tooltip showing exact completion counts and calendar dates.

### 7. 🏆 Trophy Showcase & Achievements System
* 8 unlockable badges celebrating milestones:
  * 🌱 **First Step**: Conquer your first task
  * ⚡ **Rapid Fire**: Complete 3 tasks
  * 🔥 **High-Impact Pro**: Conquer a High-Priority task
  * 🌟 **Streak Igniter**: Reach a 3-day streak
  * 📋 **Checklist Pro**: Check off nested checklist items
  * 💎 **XP Hunter**: Amass 200+ Experience Points
  * 🧘 **Deep Diver**: Complete a deep focus sprint
  * 👑 **Hyper Grandmaster**: Reach 350+ XP and 5+ tasks
* Click the XP / Streak Pod in the navbar to open the Trophy Showcase modal!

### 8. 🎧 Web Audio Synthesizer & Canvas Sound Equalizer
* Zero external audio files or network requests:
  * 🌧️ Gentle Rain generator
  * 📻 Flow White Noise
  * 🌊 Ocean Waves
  * 🧘 432Hz Binaural Alpha-Beat Focus Waves
* Live 6-band animated canvas audio equalizer visualizer.
* Tactile synthesized SFX: pop on button press, chime on task completion, swoosh on deletion, and alarm fanfare on timer finish.

### 9. 🎨 5 Iridescent Theme Suites
* 🔮 **Hyper Prism (Default)**: Cyber obsidian with iridescent violet, electric cyan, and laser magenta.
* 💎 **Liquid Pearl (Clean Luxury Light)**: High-fashion stark white & frosted glass with glowing lavender-blue accents.
* ⚡ **Cyberpunk 2077**: Deep black with radioactive neon yellow, neon cyan, and laser pink.
* 🌌 **Cosmic Nebula**: Deep stellar indigo with glowing magenta-purple aurora plumes.
* 🌿 **Emerald Matrix**: High-tech jade with radioactive mint and gold.

### 10. 📝 Smart Composer, Voice Dictation & Slide-Over Drawer
* Natural language tag parser: `!high`, `#dev`, `@tomorrow`.
* Heuristic auto-subtask generator.
* Web Speech API microphone dictation for hands-free task capture.
* Linear-style slide-over inspector drawer with nested checklists, rich notes, and 5-second undo toast on deletion.
* Dual View: Seamless toggle between Card Stream and Kanban Board with drag-and-drop.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| <kbd>N</kbd> | Focus new task composer input |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Focus search bar |
| <kbd>Z</kbd> | Toggle Distraction-Free Fullscreen Zen Focus |
| <kbd>P</kbd> | Start / Pause Focus Pomodoro Timer |
| <kbd>M</kbd> | Toggle Synthesized Audio SFX & Ambience |
| <kbd>T</kbd> | Open Themes Menu |
| <kbd>V</kbd> | Toggle List / Kanban Board view |
| <kbd>?</kbd> | Open Keyboard Shortcuts Modal |
| <kbd>Esc</kbd> | Close Slide-Over Drawer, Zen Mode, or Modals |
