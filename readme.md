# ⚡ TaskFlow — Clean & Minimal Productivity Engine

A fast, distraction-free productivity and task management web application inspired by **Linear**, **Apple**, **Notion**, and **Things 3**.

Crafted 100% with pure Vanilla HTML5, CSS3 Custom Properties, and ES6+ JavaScript — zero bundler, npm packages, or server-side dependencies required. Deployment ready out-of-the-box for Vercel, GitHub Pages, or Netlify.

🌐 **Live Deployment**: [https://taskmanager-shivam.vercel.app](https://taskmanager-shivam.vercel.app)

---

## 🌟 Key Features

### 1. 🎯 Distraction-Free Minimal Design
* Purpose-built typography system using **Plus Jakarta Sans** and **JetBrains Mono**.
* Clean light and dark themes (`[data-theme="dark"]` and `[data-theme="light"]`) with smooth CSS variable transitions and persistent preference.
* Thoughtful spacing, accessible contrast, and zero visual clutter.

### 2. ⚡ Zero Dummy Data on First Run
* Clean slate initial launch (`tasks = []`, `streak = 0`) ready for real everyday workflow.
* Optional one-click sample showcase loader available inside the Backup modal for demos and testing.

### 3. 📱 100% Mobile & Touch Responsive
* Fluid layout optimized from compact 320px smartphones to 4K desktop displays.
* Touch-friendly targets (minimum 44px), stacked mobile control rows, and horizontal scroll prevention.

### 4. 📋 Dual Views: Clean List & Kanban Board
* **List View**: Inline status toggles, priority indicators, category pills, overdue date badges, checklist counters, and double-click inline title editing.
* **Kanban Board**: Drag-and-drop cards between To Do, In Progress, and Completed columns, complete with column counters and quick-add actions.

### 5. ⏱️ Focus Studio (Pomodoro Timer)
* Built-in 25m Focus, 5m Break, and 15m Break interval presets.
* One-click task target locking: set any active task as the focus session target.
* Dynamic navigation countdown indicator that appears while focus sessions are active.

### 6. 🎧 Synthesized Audio & Ambient Soundscapes
* 100% Web Audio API procedural sound generation — no external audio files or downloads.
* Tactile UI sound effects (pop on action, chime on completion, swoosh on movement).
* Procedural ambient noise generators: Gentle Rain, Flow White Noise, Ocean Waves, and 432Hz Zen tone with an interactive volume slider and mute toggle.

### 7. 🔍 Smart Search & Multi-Criteria Filtering
* Instant real-time search across task titles, notes, categories, and checklist items.
* Filter tabs: All, Active, Completed.
* Dropdowns for Category, Priority, and Sort Ordering (Newest, Priority, Due Date, Alphabetical).
* Dynamic "Reset Filters" banner when active filters narrow results.

### 8. 📝 Slide-Over Task Inspector Drawer
* Deep inspection and editing: Title, Status, Priority, Category, Due Date, and multi-line Notes.
* Interactive checklist items: add subtasks, check them off, or delete items.
* Pinned/Starred priority bookmarking.

### 9. 💾 Data Portability & Safety
* One-click JSON backup export.
* One-click CSV spreadsheet export.
* 1-Click Undo Toast notification on task deletion to prevent accidental loss.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| <kbd>N</kbd> | Focus new task composer input |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Focus search bar |
| <kbd>P</kbd> | Start / Pause Focus Pomodoro Timer |
| <kbd>M</kbd> | Toggle Synthesized Audio SFX & Ambience |
| <kbd>T</kbd> | Toggle Light / Dark Theme |
| <kbd>V</kbd> | Toggle List / Kanban Board view |
| <kbd>?</kbd> | Open Keyboard Shortcuts Modal |
| <kbd>Esc</kbd> | Close Slide-Over Drawer or Modals |
